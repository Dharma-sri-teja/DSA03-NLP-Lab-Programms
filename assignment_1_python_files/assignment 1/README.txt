# NLP Assignment 1 - Python task files

Each file is a standalone Python example named by the assignment task number.

- `task2.py` - entity regular expressions and greedy/non-greedy matching
- `task3.py` - tokenisation and normalisation
- `task4.py` - NFA simulation, subset construction and DFA minimisation
- `task5.py` - inflectional paradigms and irregular forms
- `task6.py` - derivational affixes and attachment examples
- `task7.py` - finite-state morphology generation and analysis
- `task8.py` - ordered orthographic rewrite rules
- `task9.py` - Porter stemming and retrieval demonstration (uses NLTK if installed)
- `task10.py` - integrated miniature hospital-record pipeline
- `task12.py` - OCR repair and code-mixed token routing

Tasks 1 and 11 are primarily explanation/comparison tasks, so they do not have separate Python scripts.

Run a file from this folder with:
    python task2.py

All scripts use the Python standard library except that `task9.py` optionally uses NLTK's
PorterStemmer when NLTK is installed. These are runnable teaching implementations,
not a verbatim copy of every source file described in the assignment report.
